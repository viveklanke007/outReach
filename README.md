## 🌟 About OutReach

**OutReach** is a high-performance bulk email automation platform designed for startups and entrepreneurs. It simplifies the process of discovering leads and reaching out to them through personalized, high-speed email campaigns. 

With a focus on speed, security, and scalability, OutReach helps you turn cold leads into warm opportunities in minutes.

---

## ✨ Key Features

- **🔐 Secure OAuth 2.0 Integration**: Connect your Gmail account safely using Google's secure authentication. Your credentials never touch our servers.
- **🤖 AI-Powered Lead Discovery**: Use intelligent automation to find potential clients in any location or industry.
- **📊 Interactive Analytics**: Monitor your campaign performance with real-time charts and metrics powered by Recharts.
- **⚡ High-Speed Bulk Sending**: Dispatch hundreds of personalized emails with a single click using our optimized sending engine.
- **📱 Responsive Dashboard**: A premium, mobile-friendly interface built with Next.js and Tailwind CSS.
- **🎨 3D Visuals & Animations**: Engaging user experience featuring Three.js elements and smooth Framer Motion transitions.

---

## 🛠️ Tech Stack

- **Frontend**: Next.js 15 (App Router), React 19, Tailwind CSS 4
- **Animations**: Framer Motion, Three.js (@react-three/fiber)
- **Backend**: Next.js API Routes, Node.js
- **Database**: MongoDB with Mongoose
- **Authentication**: Next-Auth
- **Email Service**: Nodemailer, Googleapis
- **Data Handling**: PapaParse (CSV), XLSX (Excel)
- **Icons**: Lucide React

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher)
- MongoDB account (local or Atlas)
- Google Cloud Project (for OAuth 2.0 credentials)

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/viveklanke007/outReach.git
   cd outReach
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Set up Environment Variables**:
   Create a `.env.local` file in the root directory and add the following:
   ```env
   MONGODB_URI=your_mongodb_uri
   NEXTAUTH_SECRET=your_secret
   GOOGLE_CLIENT_ID=your_google_client_id
   GOOGLE_CLIENT_SECRET=your_google_client_secret
   ```

4. **Run the development server**:
   ```bash
   npm run dev
   ```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
